# QLToaNha - Apartment Rental and Monthly Fee Management System

**QLToaNha** is a web-based management system built with the **Yii2 PHP Framework** and **MySQL**. The system is designed to support apartment building administrators in managing rental contracts and handling monthly payment collections efficiently.

## 🏠 Core Features

- 📄 **Rental Contract Management**  
  - Manage tenants and rental agreements  
  - Track apartment availability and lease periods  

- 💵 **Monthly Payment Tracking**  
  - Generate and track monthly service fees and rent payments  
  - Payment status overview (Paid / Unpaid)  
  - History of all transactions per tenant  

- 👤 **User Roles & Access Control**  
  - Admin: full control of data and settings  
  - Staff: manage tenants, contracts, and billing   

- 🏢 **Apartment & Tenant Management**  
  - Add, update, or deactivate apartment units  
  - Manage tenant profiles and rental status  

- 📊 **Dashboard & Reports**  
  - View occupancy rate, revenue statistics, and overdue payments  

## 🛠️ Tech Stack

- **Language**: PHP 7.x  
- **Framework**: Yii2 (Advanced Template)  
- **Database**: MySQL  
- **Frontend**: Bootstrap, jQuery  
- **Code Generator**: Gii (for CRUD and models)
